# SAEBase Scientific Knowledge

The Knowledge Tree focuses on sparse features in language models. It includes model and SAE assets, prompt datasets, feature capture, teacher-forced interventions, generation, causal circuits, automatic explanations, benchmark reliability, and SAE training.

Each scientific question has a stable identifier, an independently maintained status, and traceable source evidence. The Code Tree is generated from real Python AST information, while the Context Tree uses [glossary.json](glossary.json) for consistent terminology.

An implemented interface establishes the existence of verifiable source code, not the validity of a scientific conclusion. Experimental effectiveness requires independent evidence.
