# SAEBase 0.8.0

SAEBase 0.8.0 organizes model inspection, activation capture, sparse autoencoder
analysis, interventions, and evaluation into a common research project layout.

- The shared runtime lives in `base/`. Data readers, models, and research tasks
  each have their own source directory and configuration.
- One configuration entry point, `conf/config.yaml`, selects the dataset,
  model, and task. Supported commands provide configuration previews and use
  task prechecks before starting research execution.
- The Research Lab, example workflows, and public Python interfaces ship with
  the project. Run the CPU quick start to generate and inspect synthetic results.

## Start here

From the repository root, install the project with `python -m pip install -e .`
and run `python scripts/examples/first_experiment.py --dry-run`. Run the same
script with `--output runs/first-experiment` to generate a local report.
See the [project README](https://github.com/OpenSAE/SAEBase/tree/v0.8.0) for
configuration previews, model dependencies, and research examples.
