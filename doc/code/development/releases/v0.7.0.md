# SAEBase v0.7.0 — Component Workflows and Reusable Experiments

SAEBase v0.7.0 publishes the current local SAEBase implementation as a complete update of the repository contents. It organizes SAE research around dataset components, model and SAE adapters, peer research tasks, and shared experiment records.

## Research workflows

- Dataset preparation, model loading, and SAE selection use their own component interfaces and explicit configuration.
- Precheck, capture, intervention, generation, circuits, explanation, benchmarking, and training are peer tasks selected through the master configuration.
- Capture includes activation-based selection, whitening, SAR, and exhaustive feature interaction measurements. Task-specific parameters and the configured model, SAE, layer, and input identity remain part of the recorded run.
- Shared runtime and storage code organize experiment output under `experiment/<dataset>/<model>/<task>/<run-name>/`, retain failures and diagnostics, and provide functions for reading, comparing, and locating reusable runs.

## Get started

Use Python 3.11 or 3.12:

```bash
git clone --branch v0.7.0 https://github.com/OpenSAE/SAEBase.git
cd SAEBase
python -m pip install -e .
python scripts/examples/first_experiment.py --dry-run
```

Inspect a task configuration before loading model weights:

```bash
saebase task=capture --cfg job
saebase task=benchmark --cfg job
```

See the [current architecture](../current-architecture.md), [Python API](../python-api.md), and [Capture guide](../../../../tasks/capture/README.md) for inputs and usage. Existing configurations and integrations should be reviewed against these current interfaces when upgrading.

## Distribution

This GitHub Release distributes the selected project source, configuration, documentation, tests, and portable development files. The attached ZIP and the GitHub source archives contain the same selected project files. Experiment outputs, local datasets, build and interpreter caches, local project bindings, and links to external local skills are excluded.

The repository is updated from the local project snapshot as a whole. Previous commits and releases remain available for earlier versions. The English and Chinese README layouts and external links are retained; their software-version references point to this release.

This publication does not add new model evaluations or reproduce historical scientific results. No wheel, source distribution built by Python packaging, PyPI publication, or hosted-service update is included in this release operation.
