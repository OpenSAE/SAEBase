# 任务工作说明

## 目的和主要功能

说明科研任务的实现、分发和共同支持职责。

## 适用范围

适用于 `tasks/` 的阅读与开发；工作模式沿用根 AGENTS.md。

- 每个任务负责自身算法、参数、指标、来源及产物协议；配置放 `conf/task/`。
- 制定任务方法和结果检查时，先确定后续研究要怎样读取、比较或继续使用本次产物，再定义输入、必要计算和输出。任务负责提供具体未完成对象、已知原因、影响和处理建议，共同保存与读取入口保留这些信息。检查过程覆盖实际结果消费，并依据各任务需要验证继续运行、补足缺失步骤或使用已有成果。
- `tasks/plugins.py` 接入统一 Registry，`saebase/runner.py` 分发任务。
- `tasks/sae_runtime.py` 提供模型、SAE 和 Prompt 资源的共同支持；通用运行路径与记录由 `saebase/runtime/` 负责。
- 激活健康评测归 benchmark，评测结果沿用现有 EvaluationResult 外层结构。
- 参数检查在负责接口中执行，配置检查保持轻量；真实 GPU 运行按用户任务授权执行。
- 接入任务时使用 `add-task` 技能。
