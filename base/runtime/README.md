# Statement of work on co-operating support

## Purpose

Maintenance of a common configuration of scientific components, training support, operational catalogues and records of results.

## Scope

Read and modify as applicable to `base/runtime/`. Maintenance is carried out in accordance with the mandate of project root AGENTS.md.

The performance, record-keeping and outcome-checking functions are developed with access and continued use at the end of the assignment: the product can be located, the specific reasons for failure or obstruction are retained with the result and the recommendations are retained, and some of the completed results are identified with the corresponding task. The status is derived from the module responsible for the fact, the indexing and displaying of the re-use it; the format is maintained, the reading interface is read and the judgement is restored. The completion is confirmed by rereading, searching and using the results after the original execution.

Positions the affected interface, direct caller and configuration prior to the change, judging whether the demand is a common support or a specific task. Describes the changes in the syntax of the default act or result; moves the actual caller when the interface is adjusted. Checks the affected call path, keeping the random seeds, logs, checkpoints and running path syntax clear.
