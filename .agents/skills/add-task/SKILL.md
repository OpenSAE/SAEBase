# 接入科研任务

## 目的和主要功能

将具体科研方法接入已有任务分发和结果读取流程。

## 适用范围

用于新增或修改捕获、生成、干预、评估、训练等 Task。输入为方法需要的输入、输出和已有相近实现；工作模式、测试选择及辅助文件处理采用根 AGENTS.md。

1. 阅读 `saebase/registry.py` 的 `TaskModule`、`saebase/runner.py`、`tasks/plugins.py` 与相近 Task。制定方法前，选定研究者或下游任务实际使用结果的场景，据此确定所需输入、计算、产物及其读取方式；同时确定实际相关的未完成情形将怎样被解释和处理。
2. 在 `tasks/<name>/` 实现任务自身的方法，沿用 `name`、`run(cfg)` 和 `EvaluationResult` 接口。
3. 通过 `tasks/plugins.py` 注册，配置放 `conf/task/<name>.yaml`；按实际变化更新 `conf/tasks_log.md`。
4. 调用已有公共支持并复用其检查结果。本任务负责自身方法特有的要求，训练任务使用训练支持，评估任务提供相应指标，其他任务按各自结果组织。
5. 通过正常任务入口生成结果，结束原执行过程后从正式入口读取，并完成预定的下游使用；按任务需要确认部分成果与处理建议能支持继续工作。任务配置与接口说明保持输入、结果含义和使用方法清楚。
