# 实验调试与修复

## 目的和主要功能

根据实际故障定位原因，将解决方式纳入正式实现，让后续实验直接正确运行。

## 适用范围

用于用户要求定位或修复实验问题时。输入为实际错误、启动命令、相关配置和运行记录；工作模式、检查范围和文件处理采用根 AGENTS.md。

1. 读取实际错误、启动命令、有效配置和所用解释器，沿相关数据集、模型、任务或 Runtime 调用定位负责模块。
2. 选择能回答当前问题的最小复现。合成输入或短运行足以定位时优先使用；检查对象由实际故障决定。
3. 临时资料放本次 `experiment/` 产物目录，保留原有实验结果；必要时使用 `SAEBASE_SMOKE` 关闭自动 TensorBoard。
4. 查明后修复正式模块，调用者共用修复后的能力。制定修复方案时，安排该故障再次发生后的实际处理：结果保留已知原因、影响及修复或定位方法，调用者能据此继续；已有的具体错误与建议直接沿用。科研维护操作归对应功能，工程维护入口放 `scripts/` 并调用正式实现；长期测试放 `tests/`，临时测试完成用途后删除。
5. 通过受影响的正式入口确认故障得到处理，将故障原因与修复依据记入本次任务资料。
