# 执行科研任务

## 目的和主要功能

通过已有任务入口运行用户选定的实验，取得该任务所需结果。

## 适用范围

用于用户要求运行科研任务或查看其结果时。输入为目标配置、数据与模型资源和运行范围。工作模式、检查范围和文件处理采用根 AGENTS.md。

1. 读取选定任务配置和实际入口，明确本次结果要支持的研究或后续动作，据此选择需要保留和读取的内容。已有配置与运行条件直接复用；遇到配置疑问时，可用 `python -m saebase.runtime.train --cfg job` 查看组合结果。
2. `python -m saebase.runtime.train` 负责共同运行流程并分发选定 Task。使用用户选择的任务与参数，复用程序已有的数据准备、兼容性和路径检查。
3. 产物按现有 `experiment/<dataset>/<model>/<task.path>/<sub_name>_<seed>` 组织，使用能区分本次运行的名称；覆盖已有结果依据用户明确要求。
4. 按用户要求选择前台或后台执行。后台运行使用现有 tmux 工具及任务目录内 `_tmp/<session>/` 日志，保存命令、日志与恢复位置。
5. 按本次任务读取结果：捕获读取特征与解释，生成读取生成内容，干预读取干预结果，评估读取指标，训练读取训练结果及适用的检查点。通过任务正式结果入口确认所需内容。
6. 取得结果后完成本次请求的实际使用，交付科研结果及其位置。受阻或部分完成时，读取具体原因和处理建议，在已有授权内继续解决；需要修正结果接口时，将缺失的解释和使用路径纳入负责模块。结果记录关联实际运行范围与协议；持续监控使用当前环境支持的方式。
