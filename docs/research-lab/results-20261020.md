## SAR measurement protocol

New analysis uses the actual residual-preserving edit:

`edited_h = h + decode(z_edited) - decode(z_original)`

Each feature coalition produces a **measured downstream scalar** `g(S)`. The exact original SAR coalition sampler and statistical estimator are then applied to these responses. The original `evaluate_sar` affine-decoder gate remains enabled **by default**; the new decoder-mediated analysis explicitly opts into a different intervention interpretation.

| Cohort | Completed original prompt groups | Config |
| --- | ---: | --- |
| K16 | **1,485** | M384, fit256, held128 |
| K8 | **14** | M128, fit96, held32 |
| K4 | **1** | M64, fit48, held16 |
| K2 | **0** | No completed groups reported |
| Total | **1,500** | Different K cohorts remain **separate** |

The reported cohorts reflect the **three selected SAR sites**; K values are **not** interchangeable statistical populations. The previous `SAE decoder is not additive` failure was addressed with an explicitly different protocol, not by silently changing the paper's estimator. The earlier feature-order permutation is **not** a valid orthogonal rotation baseline; genuine rotation controls remain pending. These data support study of a precisely defined decoder-mediated coalition response, not a claim that the original paper's affine-decoder assumption has been proved for every SAE.

## RSS measurement protocol

The recorded GPU result uses six selected model/SAE sites, **500 parent prompt groups/site**, and 45 proposed variations per parent split into distinct selection and held-out roles. The executor reports:

| Recorded quantity | Count |
| --- | ---: |
| Site × parent groups | **3,000** |
| Selected variants | **45,000** |
| Held-out variants | **90,000** |
| Shared clean inputs | **3,000** |
| Unique site–input occurrences | **138,000** |
| Historical, position-unverified nominal calls kept separately | **99,200** |

Tokenizer alignment now computes positions against actual model token IDs, rather than assuming the offset-tokenizer sequence has the same BOS prefix as the hooked model. The **99,200** previous nominal calls remain distinct from the new position-corrected population. The new labels are **“RSS under proposed transformations (not verified meaning-preserving)”**: no claim is made that every wrapper preserves task semantics.

The reported 138,000 are **logical site/input occurrences**, not independent prompt groups, model-forward counts, or a guarantee that all raw arrays have been independently inspected.

## Localize and interventions

The exact six-factor, 64-state controlled input design is one statistical population. The new real-model result restricts exact optimization to **55 features observed as nonzero somewhere on that grid**, retaining original dictionary identities. Zero columns on that **specific finite grid** do not contribute variation there; the synthetic zero-column parity test supports this numerical reduction. It is not a proof of feature irrelevance on other inputs.

Six deep-dive sites have genuine intervention logit pairs. **Full edited text generation for this Research Lab experiment remains pending**; logits/top-5 tokens are not presented as complete steerable generation.

## Identity, licensing and distribution limits

- Three historical sites have incomplete original model/SAE state hashes; one Gemma-2-2B IT L12 load differs from its non-empty historical hash. A genuinely loaded checkpoint can be recorded as a **new experiment identity** but not backfilled as the old match.
- The source lock references exact upstream dataset commits. Human rights review, source-content inspection and meaning-preservation review remain pending. The public code release contains no unapproved original prompt texts.
- The observed GPU experiments use `experiments/research-lab/7fb2be8f29a1-20261019T035727Z` on the original GPU host. This folder is intentionally gitignored; its full archive and second-location verification are separate from software release.
- The local CPU Research Lab Docker image browses **historically verified** Stage D evidence by default. It does **not** automatically expose private GPU experiments, and the public online GPU endpoint is disabled.
