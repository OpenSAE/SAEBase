# Execution scripts

Keep shell launchers under this top-level directory. Prefer `scripts/workplan/<id>.sh`, `scripts/<dataset>/<model>/<task>/<sub_name>/` or `scripts/experiments/<study>/`. This organization is flexible: document ownership and purpose when deviating. Do not place ad hoc shell scripts in Dataset, Model or Task modules.

See [architecture rules](../harness/core/BOUNDARIES.en.md).
