# R15 十二组 replacement 搜索与独立确认

用真实SAEBase intervention搜索两个feature与三个绝对replacement值，在两条validation prompt上最小化平均logit_delta_l2；冻结最佳配置后，用两条heldout test prompt各确认一次。目标仅是在给定replacement候选中尽量保持模型输出。

## 基线与既有行为

无需产品代码变更。薄runner直接使用真实SAEBase API，禁止构建独立fake evaluator；12个trial指12次参数条件，必要的选择与baseline forward单独记账。

基线提交为 `41a54cbfdee5cce24d3d8f7517aadef0c752c5ac`，[原始源码快照](https://github.com/OpenSAE/SAEBase/tree/41a54cbfdee5cce24d3d8f7517aadef0c752c5ac)。运行profile为 `gemma_inference`。本题没有额外instructor seed。

## 具体执行步骤

1. 从common train split取前2条作feature选择，validation split取前2条作搜索评估，test split前2条仅作最终确认；记录三个集合无sample/prompt_group重叠。test内容与结果在best_config冻结前不参与任何选择。
2. 用真实capture计算选择集每个feature的mean absolute activation，按该值下降、ID升序取两个非零feature，并在评估前写入只读selection.json冻结IDs。若不足两个，报告明确阻塞，不扩大数据量。
3. 冻结完整grid为两个feature IDs×replacement_values=[0.0,1.0,2.0]×两个validation prompt IDs，共12个不同trial IDs、6个feature/value候选。每次只替换一个feature；value是绝对SAE code值。
4. 冻结优化目标J(f,v)=(delta_l2(f,v,p1)+delta_l2(f,v,p2))/2，取MIN。排序key为(J,feature_id,value)，J完全相等时按feature_id再value升序；两个validation结果缺任意一条，候选不具备完整目标，整个网格保持partial。
5. 逐validation trial调用evaluate_edit(replacements={feature_id:value})，默认identity verification开启。保存baseline/edited logits、实际replacement code、logit_delta_l2、max_abs_logit_change及source/config/input身份。
6. 独立复算12条测量及6个J，核对笛卡尔积缺项/重复；完整网格才可将argmin写入best_config.json，包含selection/grid/source/validation产物hash并冻结文件。
7. 冻结best_config后，在此前未用于选择的两条test prompt上各运行一次该feature/value，共2次confirmation；保存confirmation_rows.jsonl和原始logits。不得根据test表现更换feature/value、追加候选或再次选择。
8. 总干预trial固定14次，其中12次validation网格加2次heldout确认；另有2条train prompt的feature选择capture，全部记录计算与耗时。输出validation目标值、唯一best config及heldout实测值，明确小工程目标和小样本范围，不宣称科学改善。

## 必须通过的正例

1. validation恰好12个唯一完整组合，对应6个feature/value候选；每条均有真实模型测量与输入身份。
2. 实际选定code等于绝对value，而非原值乘value；指标与真实logits独立复算一致。
3. 六个目标J都按两条validation结果的算术均值计算，best_config确为冻结排序规则的argmin。
4. best_config在访问heldout结果之前冻结，其hash在确认后不变；test两条仅各运行该配置一次。
5. 总14个干预trial完整，2条选择输入、2条validation与2条test来源及用途可复查；失败/缺项不补成0。
6. 独立检查可发现一个使用最大值、错误均值或错误并列规则的selector；该检查可用小型数值负例，真实最佳配置仍来自真实12条网格。

## 必须检查的负例

1. 重复或遗漏validation trial、NaN replacement或越界feature必须失败或明确partial，不能选择best并宣布完成。
2. 把replacement当scale、最大化而非最小化J、错误处理平局，均必须被检查发现。
3. 根据validation结果重新挑feature IDs、在best冻结前使用test内容/结果调参、确认后重新选择best，均判失败。
4. 两条heldout test上测试多个候选、追加test试验或复写best_config判失败。
5. 复制同一测量为不同trial，或仅改参数标签而没有真实forward，判失败。

这些验收条件在出题时冻结。评分者可以用不同合法输入重放同一条件，不能看过考生实现后新增需求。
