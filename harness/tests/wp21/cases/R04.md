## 具体执行步骤

1. 先记录当前 reconstruction_l2 的实际定义为 vector_norm(snapshot.reconstruction)，避免把旧字段重新解释成误差。
2. 新增 reconstruction_error_l2，使用 snapshot.activation.float() 与 snapshot.reconstruction.float() 的差计算；原字段继续计算重建向量范数。
3. 用 common/prompts.jsonl 前 4 条记录、同一真实 Gemma/SAE 运行 capture，保存 activation 与 reconstruction 的原始小型张量。
4. 独立复算两个范数及可选的 MSE 对照，明确 L2 与 MSE 的单位和归一化差别；新正式字段只要求 L2。
5. 对默认 capture 的其它字段做兼容比较。

## 必须通过的正例

1. 每条记录的 reconstruction_error_l2 与原始向量差的独立 L2 计算一致，rtol=1e-5、atol=1e-5。
2. 旧 reconstruction_l2 仍等于 reconstruction 向量范数。
3. 输出指标为有限非负数，字段名与公式在 report 中对应。
4. 记录数、prompt SHA、feature_count 等旧接口保持。

## 必须检查的负例

1. 检查器必须发现把 ||reconstruction||₂ 再复制一遍当误差的错误实现。
2. 检查器必须发现把 MSE 或 squared L2 填进新字段的错误实现。
3. 非有限 activation/reconstruction 的小型负例必须失败，不能序列化 NaN 为成功。
4. shape 不匹配的负例不得通过广播悄悄产生指标。

这些验收条件在出题时冻结。评分者可以用不同合法输入重放同一条件，不能看过考生实现后新增需求。
