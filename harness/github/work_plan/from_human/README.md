# from_human · human intent records

Before writing or materially revising a Work Plan, preserve the user's **confirmed** research goal, motivation, Atlas Core/Knowledge/Context references, accepted decisions, constraints, budgets, scope, expected deliverables, and unresolved questions.

Use `TEMPLATE.md`. Capture only confirmed information. An absent answer is `unresolved`, not a guessed requirement. Do not include private credentials, user-specific secrets, or unapproved private research text in this public repository.

The record is **planning context**, not permission to run GPU jobs, download gated files, upload to B2, change code, merge PRs or publish. An approved Work Plan is the task specification; authorization remains separate. Preserve revised decisions with a revision/date and source reference instead of erasing previous human input.

The `from-human-json` block binds the human record to the Work Plan identity. Detailed discussions may remain in prose and need not be duplicated in the executable Work Plan. Plan validation cross-checks this file, Work Plan references and current Atlas identities.
