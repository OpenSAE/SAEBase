# WP23 · Human Intent

## Confirmed human goal

WP23 必须是一项完全独立、自己定义默认检查范围和执行方式的通用 Precheck 任务。它建设并验证 Dataset、Model、SAE 与兼容性检测，具有真实资源校验、可恢复运行和审计能力。不得引用或继承任何其他 Workplan 的实验配置、执行范围或成果。

## Confirmed workflow and approval conditions

- 第 3 阶段允许记录和起草；第 7 阶段必须准备好所有必要功能、配置、启动入口及测试。
- 只有通过 Agent Ready 的独立执行型 Workplan 才能交给 Local Agent，Agent 不负责现场设计通用软件模块。
- 起草后先提供逐章节人类摘要，再分别审阅 Code / Knowledge / Environment / Core / Harness / Context 六域影响。
- 源码写入范围与 Atlas 节点变更独立审核；本次仅要求重新起草并更新草案，不批准功能源码修改或真实运行。
- 本任务没有获得任何跨 Workplan 引用或依赖授权。

## Proposed technical defaults — pending human review

- 以当前权威 Registry 中的活跃 Dataset、Model 及各 Model 所属 SAE Profile 为候选。
- 每个 Model 默认检查最多两个显式 SAE Site，不存在对象时出具明确阻塞。
- 默认 Inventory、Dataset、Model、SAE Site、兼容性及 Capture/Intervene/Generate/Benchmark 有界 smoke；对每个合法 Pair 最多两条真实输入。
- 默认禁用网络、下载、GPU、Native、发布；真实资源预算在目标环境测量并单独批准。

## Decisions still requiring human authorization

候选文件的源码编辑、是否需要 Atlas Node Human Check、额外模型资产授权、真实 GPU 和付费资源预算、Native/远端备份/发布均未获批准。草案中的拟议技术默认参数不应被表述为已经完成的人类审批。
