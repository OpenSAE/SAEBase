# WP23 · Human research intent（已确认的需求记录）

## Confirmed research goal
在 SAEBase 中建立并系统验证通用 Dataset / Model / SAE / Compatibility Precheck，使用 WP22 的 QA500 固定 10 个数据集、10 个模型、20 个 SAE 位点作为首个真实验收场景。最终 Precheck 能在干净机器上准备所需资源，逐项执行有界真实检查，给出可恢复、可审计的完整收据，随后向 WP22 Pilot 提供准确门禁。

## Scientific and engineering motivation
WP22 需要真实可复核的模型/SAE/数据输入与激活前置保证；此前 Setup、Precheck、Audit 刚完成架构重构，但在主分支中尚未证明任意 Dataset 与多组件组合的通用真实检查。WP23 的贡献是可复用的软件/科研执行可信度，不是 QA 新评分指标或独立科研结论。

## Confirmed decisions / scope
- WP22 选择仍为 10 个真实 QA 数据集×每源 500 题，10 个指定 Model×两个明确 SAE Layer/Site；不得改题目、模型、SAE、Hook、评分器、seed、限制或发布协议。
- 独立组件覆盖目标为 Dataset 10、Model 10、SAE Site 20；声明的兼容目标为 Model×Dataset 100、SAE Site×Dataset 200，按实际兼容性逐项记录，不扩展到其他模型 SAE 的错误笛卡尔积。
- 建议兼容检查每目标使用 1–2 条固定真实 QA 输入，是 Precheck 最小检测预算，不能替代 WP22 冻结的 10 题 Pilot / 500 题正式测量。
- Setup 只做资源准备；真实检查只能在批准的 Precheck / Worker 阶段。按依赖切分失败范围，独立项继续并保留阻塞收据。
- 审阅通过前不得修改功能代码；此轮仅拟定计划与 Human Check，未授予 GPU、联网下载、Native Training、B2、HF 发布或付费预算。
- 输出：完成填写的原始 Workplan 副本、component_checks.csv、compatibility_checks.csv、task_checks.csv、coverage_summary.csv、原始收据、Audit、manifest、archive/SKIPPED 收据。

## Unresolved decisions (not implied consent)
- 真实机器 GPU 型号与可用 VRAM、硬盘、网络及 gated HF 权限未确认。
- 具体实际运行总时长与每工作器预算，应在环境测量后提交审批；不得把计划中的建议样本量当作运行许可。
- WP22 分支同最新 main 的合并冲突与旧 sae import 迁移，须做精确源码复核；不批准更改冻结科学参数。
- Native Circuits/Train 的真实执行及任何远程备份、公共发布需要独立授权。
