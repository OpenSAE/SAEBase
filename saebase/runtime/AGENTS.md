# 共同运行支持工作说明

## 目的和主要功能

维护各科研组件共用的配置、训练支持、运行目录和结果记录。

## 适用范围

适用于 `saebase/runtime/` 的阅读与修改；工作模式沿用根 AGENTS.md。

制定运行、记录和结果检查功能时，同时安排任务结束后的读取与继续使用：产物能够定位，失败或受阻的具体原因与建议随结果保留，部分完成的成果能被对应任务识别。状态来自负责该事实的模块，索引与显示复用它；保存格式、读取接口和恢复判断一同维护。通过结束原执行过程后重新读取、查询和使用结果确认完成情况。

修改前定位受影响的接口、直接调用者和配置，判断需求属于共同支持还是具体任务。说明默认行为或结果语义的变化；接口调整时迁移实际调用者。检查受影响的调用路径，保持随机种子、日志、checkpoint 和运行路径语义清楚。
