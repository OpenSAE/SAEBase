# 长实验状态恢复

1. 确定当前环境、原始启动命令、GPU/进程或 tmux 会话、日志位置、Hydra 保存配置及 checkpoint。
2. 检查作业究竟正在运行、正常完成、被中断还是已经失败；不能凭旧对话或目录存在推断进度。
3. 正在运行则读取日志与可用指标，并在会话内按工具能力合理等待；不终止健康作业，也不擅自启动同名重复作业。
4. 需要恢复时，先验证 Task 是否真的支持 checkpoint 恢复；若不支持，说明限制，不能假称已有续训能力。
5. 若用户明确要求后台，使用 tmux 和具体 experiment/<dataset>/<model>/<task.path>/_tmp/<session>/ 日志；保存可再现的命令、配置、运行叶子及日志路径。
6. 交付实际状态和下一步；不能承诺当前会话结束后自行持续工作，除非有明确支持的调度机制。
