# SAEBase Research Lab

Feature Atlas opens at `#play`. Feature Effects names one measured feature and compares the next-token forecast with that feature on and off. Context Lab shows a 64-state authored input grid and measured input transformations. Built with OpenSAE and the [SAEBase-Evaluation](https://huggingface.co/datasets/OpenSAE/SAEBase-Evaluation) dataset.
